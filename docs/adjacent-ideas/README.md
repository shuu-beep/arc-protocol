# Adjacent Ideas

> **Status:** Speculative notes outside ARC core scope

The documents in this directory are not part of the ARC core protocol proposal.

They explore ideas that may be philosophically adjacent to ARC, such as information sovereignty, agent-mediated collaboration, discovery transparency, or user-controlled curation.

They should not be read as current ARC requirements, MVP scope, protocol commitments, or implementation plans.

ARC's current core scope remains human-approved agent commerce: structured offers, approval boundaries, reputation, identity, governance, and failure analysis for commerce coordination.

Adjacent ideas may be useful for future thinking, but they should not blur the current project boundary.
